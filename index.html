How the Carta Lotto Chart Works

Each Carta Lotto chart is presented as a 4×4 matrix containing sixteen digits. Four positions within the matrix are visually highlighted to make the chart easier to inspect. GDL Perdana charts use a light red highlight, while the MTP and SGP chart uses a light gold highlight.

The highlighted positions are simply part of the chart's visual presentation. Visitors can review the complete matrix rather than focusing only on the highlighted cells. Previous dated charts can also be compared with the latest update when that information is useful.
